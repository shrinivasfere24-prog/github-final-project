# Simple Interest Calculator

A command-line tool built in Bash that calculates simple interest based on user-provided inputs.

## Overview

This project takes three inputs from the user:
- **Principal amount** — the initial sum of money
- **Rate of interest** — annual interest rate (in percent)
- **Time period** — duration in years

It then calculates simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100


## How to Run

1. Clone this repository:

git clone https://github.com/shrinivasfere24-prog/github-final-project.git
cd github-final-project

2. Make the script executable:

chmod +x simple-interest.sh

3. Run the script:

./simple-interest.sh

4. Enter the requested values when prompted.

## Example

Enter principal amount: 1000
Enter rate of interest (%): 5
Enter time period (years): 2
Simple Interest = 100
